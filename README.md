# Blips Chizt Homebrew Tap

Homebrew tap for software published by the
[blips-chizt](https://github.com/blips-chizt) organization.

## Install Hover Translate

```sh
brew install --cask blips-chizt/tap/hover-translate
```

Hover Translate requires macOS 15.2 or later. The distributed app is a
universal binary supporting Apple Silicon and Intel Macs.

## Upgrade

```sh
brew upgrade --cask hover-translate
```

## Uninstall

```sh
brew uninstall --cask hover-translate
```

## Packages

Graphical macOS applications are maintained in `Casks/`. Command-line tools,
services and libraries may be added to `Formula/` in the future.
